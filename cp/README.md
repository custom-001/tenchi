# cp (tenchi)

cp: copies an input file and pastes the contents into another file, and that's what all it can do lol.

## very simple things to know

### usage
```bash
cp [input] [output]
```

yes, that easy to use

### flags and options
still none

### example use
if you have a file named hi.txt that has "hi" inside it and you want to copy what's inside that file to hello.txt.
```bash
cp hi.txt hello.txt
```

it would place the word "hi" inside hello.txt, cat it and prove me wrong.
