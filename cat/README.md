# cat (tenchi)

cat: concatenate files and outputs in stdout (standard output), and that's what all it can do.

## simple things to know

### usage
```bash
cat [files]
```

that simple to use.

### flags and options
none

### example use
let's say you have a file named hello.txt, with a line of text saying "hello"
when you do
```bash
cat hello.txt
```

it would simply output
```bash
hello
```
