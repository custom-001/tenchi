# ls (tenchi)

ls: lists every contents of a directory, and yes, that's all it can do

## another very simple thing to know

### usage
```bash
ls [optionally a directory you want to see what contents are inside it]
```

### flags and options
yes there is something and that is nothing

### example use
if in your working directory you have files like milk.bin and water.bin
```bash
ls
```

would output
```bash
milk.bin
water.bin
```

and if you want to see stuff inside a directory
```bash
ls ~/directory_you_chose
```

would probably output
```bash
wood.bin
dirt.bin
```
